
# DEV ORGANIZERS

Official multi-page event management website frontend.

## About

DEV ORGANIZERS is an event management organization website based in Bengaluru, Karnataka.

The website provides information about event planning services and allows customers to submit event inquiries through a booking form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

## Website Pages

1. Home
2. About Us
3. Services
4. Gallery
5. Booking
6. Contact Us

## Running the Website

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Navigate through the website using the menu.

You can also use the VS Code Live Server extension.
